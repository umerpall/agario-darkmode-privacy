Privacy Policy for Agar.io Dark Mode

Last updated: September 2026

1. Information Collection

Agar.io Dark Mode does not collect, store, track, or transmit any personal data or personally identifiable information. All code runs entirely locally within your browser to apply visual styling to agar.io.

2. Data Usage

Since no user data is collected, no data is sold, transferred, or shared with any third parties under any circumstances.

3. Permissions

The extension only requests permissions required to inject CSS and local scripts onto agar.io web pages to display the dark theme interface.

4. Contact Information

If you have any questions or feedback regarding this privacy policy, please contact us via our official repository or developer profile.
